# 🧠 AI Clinic Search

**AI Clinic Search** is a WordPress plugin that integrates an intelligent clinic search system powered by AI.  
It automatically connects to **Google Custom Search API** to gather clinic and private hospital information, then uses AI models to extract and structure key contact data such as addresses, emails, phone numbers, and websites.

The user interface is built with **React** and **Ant Design**, providing a fast and intuitive search experience within WordPress.

---

## ✨ Features

- 🔍 Smart search for clinics and private hospitals using Google Custom Search API  
- 🧠 AI-powered data extraction (address, phone, email, website, etc.)  
- ⚡ Fast and responsive UI built with React + Ant Design  
- 📬 Integrated actions: contact via email, Zalo, or schedule an appointment if available  
- 🔗 Easy embedding into any WordPress page via shortcode
